# Code of conduct

Be straightforward and be specific. Argue about the evidence, not the person.

Concretely, in issues, pull requests and discussions: describe what you observed and how
someone can reproduce it; assume the other person read the same documents you did; and
do not post anyone's private keys, seed phrases, personal data or private correspondence.

For anything serious — harassment, doxxing, or a security disclosure posted in the
open — contact the maintainers privately (see [SECURITY.md](SECURITY.md)) rather than
replying in the thread.

This applies to every repository in the `musepass` organisation.
