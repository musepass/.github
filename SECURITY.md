# Security

Report a vulnerability privately through GitHub:
**Security → Report a vulnerability** on
[musepass/musepass](https://github.com/musepass/musepass/security/advisories/new).

The project's `SECURITY.md` lists the weaknesses we already know about — the registry
admin key, the single-host deployment, the gateway signer. Reporting those again is not
a finding; they are written down on purpose, and the same list is public on the
[trust page](https://musepass.xyz/trust).

Do not open a public issue for anything that could take a name away from its owner.
